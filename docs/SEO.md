# SEO & Social Sharing

## Public URLs
Use stable, human-readable URLs, for example:
`/investigation/INV-2026-00123/sample-investigation-title`

## Metadata
Each public investigation should generate:
- unique title
- meta description from summary
- canonical URL
- Open Graph title/description/image
- social card metadata
- robots directives based on publication/visibility status

## Structured data
Use JSON-LD where accurate and semantically appropriate. Do not fabricate author, publisher, date, location, or other facts not present in the record.

## Sitemap
Include indexable public investigation pages, investigator public profiles, categories, and policy pages as appropriate.

## Search indexing
MySQL search is the source of truth initially. Search-engine discoverability and internal search are separate concerns.
