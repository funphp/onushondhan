# UI / UX Specification

## Design direction
Professional investigative publishing platform. The visual language should be credible, readable, restrained, accessible, and content-first. Avoid sensational tabloid styling.

- Contact

## Admin pages
Dashboard, users, investigators, investigations, evidence, comments, tips, complaints, moderation, roles, permissions, CMS, agreements, analytics, audit logs, settings.

## Investigation editor
Use a multi-section editor with visible save state, validation, draft status, preview, evidence upload, source management, findings, timeline, identity selection, and final responsibility confirmation.

## Responsibility confirmation
Before publishing, show a clear confirmation that:
- the investigator is responsible for the report's claims and supporting material;
- they have the rights/permissions needed for submitted material;
- publication is subject to platform policies and applicable law;
- publication by Onushondhan does not represent independent verification or endorsement.

Require an explicit confirmation interaction and record its timestamp/version.

## Accessibility
Target WCAG 2.2 AA practices where practical: labels, keyboard navigation, focus states, color contrast, alt text, semantic landmarks, accessible dialogs, validation messages, and reduced-motion support.

## Responsive behavior
Design mobile-first. Public investigation reading should remain comfortable on small screens. Tables in admin should become scrollable or card-based on narrow screens.
