# Local site on the Vagrant VM (`http://onusondhan.local`)

The shared Vagrant VM (`192.168.33.22`) runs the app with the same routing as production:

| Piece | Where |
|---|---|
| Apache vhost | `/etc/apache2/sites-available/onusondhan.local.conf` (original kept as `*.bak-20260924`). `/api`, `/sanctum`, `/admin`, `/livewire` and Filament assets → Laravel via PHP 8.3-FPM (`/opt/php8.3`, `/run/php/php8.3-fpm.sock`); everything else → Next.js on `127.0.0.1:3300`. `ServerAlias onusondhan.test`. |
| Laravel | `/var/www/html/onusondhan/backend` (shared folder), DB `onushondhan_dev`, `.env` has `APP_URL=FRONTEND_URL=http://onusondhan.local` |
| PHP limits | `/opt/php8.3/etc/conf.d/onushondhan.ini` (uploads 105 MB) |
| Next.js | build in `/opt/onushondhan-web`, systemd `onushondhan-next.service` (www-data) |
| Queue worker | systemd `onushondhan-queue.service` (PHP 8.3, database queue) |
| VM hosts entry | `127.0.0.1 onusondhan.local` so server-side rendering calls Apache locally |

Demo accounts (local only), password `Onushondhan#2026`: `reader@`, `reader2@`, `investigator@`,
`investigator2@`, `moderator@`, `admin@`, `superadmin@onushondhan.test`. Admin panel:
`http://onusondhan.local/admin`. Outgoing emails (verification, password reset) are written to
`backend/storage/logs/mail.log`.

## Common tasks

```bash
scripts/local-vm-frontend.sh                         # rebuild + redeploy the frontend after frontend changes
vagrant ssh -c 'sudo systemctl restart onushondhan-queue'   # after backend job/service changes
vagrant ssh -c 'cd /var/www/html/onusondhan/backend && sudo -u www-data /opt/php8.3/bin/php artisan migrate:fresh --seed --force'   # reset demo data
```

Backend PHP changes are live immediately (shared folder). E2E against this site:

```bash
cd frontend && E2E_BASE_URL=http://onusondhan.local E2E_HOST_RULES="MAP onusondhan.local 192.168.33.22" \
  E2E_MAIL_LOG=$PWD/../backend/storage/logs/mail.log npx playwright test
```
(E2E adds test data to the dev database; reset it afterwards.)

## macOS `.local` lookup delay

macOS resolves `*.local` through Bonjour first, so the first request after a pause can take ~5 s
before `/etc/hosts` is used. Either ignore it (browsers cache DNS) or use the alias:
`sudo sh -c 'echo "192.168.33.22 onusondhan.test" >> /etc/hosts'` and open `http://onusondhan.test`
(links generated by the app still point to `onusondhan.local`).
